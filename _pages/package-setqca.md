`setqca` is a native Python toolkit for crisp-set and fuzzy-set Qualitative Comparative Analysis. It is research-methods software: the goal is to support configurational explanation, case comparison and transparent set-theoretic reasoning.

## Install

```bash
pip install setqca
```

## Where It Fits

Use this package when the analysis is about necessary and sufficient conditions, configurations of causes, fuzzy-set calibration or comparative case logic rather than conventional prediction alone.
