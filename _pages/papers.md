## Research-Code Companions

These repositories support or reproduce research arguments but are primarily code companions rather than standalone manuscripts.

- [brat-boosting](https://github.com/DiogoRibeiro7/brat-boosting) — Python implementation of Boulevard Regularized Additive regression Trees with statistical inference.
- [sssp_research_lab](https://github.com/DiogoRibeiro7/sssp_research_lab) — Implementable shortest-path algorithms inspired by sorting-barrier SSSP research.
- [adaptive-importance-sampling](https://github.com/DiogoRibeiro7/adaptive-importance-sampling) — Safe cross-entropy-based importance sampling for rare-event simulations.
- [ann-variable-selection-refutation](https://github.com/DiogoRibeiro7/ann-variable-selection-refutation) — Reproduction and stress test of ANN variable selection from t-statistics.
- [pca-cautionary-tale](https://github.com/DiogoRibeiro7/pca-cautionary-tale) — Reproducible PCA reliability workflow using PCA, t-SNE, persistent homology and cosine-distance modelling.

## Inclusion Rule

I list public repositories when they contain at least one of: manuscript source, PDF output, bibliography, notebooks, replication code, or a documented research report. Private repositories and unpublished work without public source are intentionally excluded.
